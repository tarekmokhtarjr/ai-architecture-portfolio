# AI Architecture Course Repository

This repository is dedicated to the AI Architecture course. It serves as a central hub for all course materials, assignments, and projects.

## Folders Hierarchy

- **README.md**: Contains an overview of the repository, including scenarios, assumptions, and instructions on how to read the repository.
- **docs/**: Contains one markdown file per session, such as `01-framing.md`, `02-building-blocks.md`, etc. These files provide detailed documentation for each session.
- **diagrams/**: Stores exported PNG and SVG diagrams, along with their source files. This folder helps in visualizing architectural components and designs.
- **adr/**: Houses Architecture Decision Records (ADRs) as separate markdown files, e.g., `0001-model-hosting.md`. ADRs document significant architectural decisions and their rationales.
- **capstone/**: Contains the final architecture deliverables, including a PDF and presentation slides for the capstone project.
